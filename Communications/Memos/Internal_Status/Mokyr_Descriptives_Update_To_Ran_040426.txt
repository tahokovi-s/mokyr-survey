Separate update on Legacy. Some of this you already know, but it helps me to write it out clearly, so apologies if I am repeating myself. This is the project asking whether elite colleges have "dynasties," families whose surnames persist at the same institution generation after generation, beyond what general socioeconomic persistence would predict. The key test is whether a surname's historical concentration at a given college (say, Harvard) predicts its modern concentration at that same college more than it predicts concentration at other elite colleges (say, Yale or Princeton). If the persistence is stronger along that diagonal, something college-specific is at work.

Since mid-March I have been working on the estimation side. The earlier specifications Santi and I discussed were producing magnitudes that felt implausibly large for some school-cohort combinations, so the goal has been to compare different statistical approaches and find one that gives defensible estimates.

I moved the estimation off Redivis (which was hitting memory limits) and onto Sherlock, where we have more resources. I built three alternative model specifications: an overrepresentation logit that asks a clean yes/no question about historical concentration, a weighted linear model that lets us separate the contribution of earlier vs. later historical cohorts, and a log-binomial model (closest to what Santi originally proposed) that estimates relative-risk ratios. Each specification runs with and without about 104 surname-level controls (racial composition, foreign-born parent shares, state of origin), and across four different ways of constructing the modern LinkedIn sample, so that we can check whether the results depend on how we build the data.

I've been running earlier versions of this comparison over the past two weeks, and I've had to fix errors as they came up in each round. The job currently running on Sherlock is the second iteration of the code, built to account for the issues that've come up so far. It covers 120 model runs (all combinations of specification, controls, sample variant, and school scope) and should finish tomorrow (April 5). Each job takes roughly 24 hours on Sherlock's fast hardware. The reason it takes that long is that each of the 120 runs fits hundreds to thousands of individual regressions (one for every pair of schools in the scope), and the controlled versions add 104 covariates to each regression, so the full grid adds up to tens of thousands of model fits. Once the results land, I will take a careful look at the full set of outputs and pass along a summary to you and Santi for discussion on next steps.
